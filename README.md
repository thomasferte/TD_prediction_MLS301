# TD prédiction M2 SITIS

## Data

Ce dossier contient le fichier tbl_stroke.csv qui est la base de donnée utilisée dans le TD. Le fichier prepare_base_sns.R a servi à générer ces données.

## Student

Ce dossier contient le notebook sans la correction à destination des étudiants.

## Fichiers à la racine

DAG.txt contient le DAG utile pour identifier les facteurs d'ajustement à inclure dans le modèle.

generate_td_html.py permet de générer les versions étudiant et enseignant du TD (à partir des tags solution)

requirement.txt liste les modules python requis

student.tpl est appeler par generate_td_html.py pour générer la version étudiant.

td_prediction.ipynb correspond au corps du TD principal avec la correction.
